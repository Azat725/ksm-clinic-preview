# КСМ · демонстрационная версия

[Открыть демонстрацию](https://azat725.github.io/ksm-clinic-preview/)

Прототип сайта клиники в Казани на React, TypeScript и Vite. Включает главную страницу, каталог и четыре профиля специалистов. Запись ведёт к телефону регистратуры. Виджет карты загружается по нажатию пользователя.

Перед официальным запуском нужно согласовать с клиникой сведения о специалистах, цены и права на использование материалов. Публичная демонстрация помечена noindex.

## Локальный запуск

Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Адрес разработки: http://localhost:4173/medic_corp/.

```sh
npm run build
npm run preview
```

Адрес локального предпросмотра: http://localhost:4174/medic_corp/.

GitHub Actions публикует сборку из ветки main. В workflow путь Vite задаётся по имени репозитория.

Портреты и логотип используются для демонстрации. Источник: [официальный сайт КСМ](https://ksm-eko.ru/).
